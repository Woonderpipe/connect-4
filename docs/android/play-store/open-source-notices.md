# Android open-source notices

The Android distribution includes the web application and native dependencies. Their applicable license and attribution information is available through the in-app Open Source Licenses screen and the generated repository notice file.

The catalog includes resolved web packages, Android runtime dependencies, license identifiers, source links, attribution text, and license text where available. It is regenerated when dependency metadata changes.

The notice locations are:

- In-app: `/open-source` (English) and `/de/open-source` (German).
- Repository: /docs/third_party/THIRD_PARTY_NOTICES.md/.
- Project notices: /NOTICE/.

Unknown or contradictory metadata should be resolved against the upstream package or replaced before distributing the affected build.
