# AI Polish Pass

Mode: AI-assisted image editing. Each deterministic 1080x1920 composite was inspected, edited individually, copied into `source/ai-polish/en/`, normalized back to 1080x1920 RGB PNG, and inspected again. The renderer uses these project-local polished masters when present.

Common invariants

- Use the app's Segoe UI / system sans visual language.
- Keep the exact campaign headline and subhead; add no claims, CTA, rating, badge, or watermark.
- Keep gameplay active: no PAUSE overlay.
- Keep authentic feature wording; no Next.js portal or scrollbar.
- Replace rigid manual boxes and pills with lighting-led, scene-integrated typography treatments.

## Per-image edit directions

1. **Hero:** premium red/blue energy rim lighting; preserve gameplay and copy.
2. **Modes:** rebalance the split arena so `Play your way` never overlaps the real mode selector.
3. **Variants:** create a clear portal-lit copy area while preserving Pop-Out, Gravity, Bomb Disc, Wild Spots, Power-Up, Rising Floor, and Connect 5.
4. **Online:** move copy into clear network-energy space; preserve Create New Game, Enter Game Code, Join, and correct `Bomb Disc` label.
5. **Customize:** integrate copy into the personalization light ring; preserve timer, language, dark mode, and tabletop controls.
6. **Languages:** preserve every Arabic RTL character and control; use celebratory ribbon light with no scrollbar.
7. **Tabletop:** enlarge the realistic iPhone-like phone; show exactly two anatomically correct hands touching the active board from opposite sides; preserve one-device tabletop play.

The notes above are the stable reproducibility brief for future iterations.
