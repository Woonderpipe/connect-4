# Documentation

This directory contains concise public documentation for the web application and its Android wrapper. Instance-specific deployment notes, credentials, and internal release records are kept outside the repository.

## Using the app

- Start a local game and choose a local or AI mode.
- Use the online mode to create or join a match through an invite link.
- Use Unlimited for games without a countdown.
- Local settings and statistics are stored in browser or Android WebView storage.
