## Automation

License catalogs and notices are generated from resolved package and Android dependency metadata. Generated output is evidence for attribution review and should be regenerated when dependencies change. Search-engine ownership verification is separate from analytics: Google Search Console and Bing Webmaster Tools use site-verification tokens, while Umami is the optional analytics service.
